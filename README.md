# Event and Ticket Booking Platform

A Django web application for managing events, ticket availability, temporary reservations, and order processing.

## Features

- **Event management:** Create and manage events with organizer information and approval statuses.
- **Organizer profiles:** Associate events with their organizers.
- **Ticket management:** Define ticket types, prices, and available quantities.
- **Ticket reservations:** Temporarily reserve tickets with an expiration time.
- **Order management:** Track orders and their statuses.
- **Price change approval:** Implement an approval workflow for ticket price changes.
- **Authentication and permissions:** Use Django authentication and access controls to manage user actions.

## Technologies

- Python
- Django
- SQLite
- HTML and Django Templates
- Pillow
